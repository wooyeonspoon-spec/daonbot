연결하지 못했어요

이렇게 해 보세요
1. 다온봇 앱이 켜져 있는지 확인해 주세요.
2. 주소창 근처에 "이 기기의 다른 앱 및 서비스에 연결" 같은 허용 창이 뜨면 [허용]을 눌러 주세요.
3. 실수로 [차단]을 눌렀다면 주소창 왼쪽 자물쇠(또는 설정) 아이콘 → 사이트 설정 → 로컬 네트워크 접근 → 허용으로 바꿔 주세요.
   그다음 아래 [다시 시도]를 눌러 주세요.
4. 계속 안 되면 Chrome / Edge 브라우저로 열어 주세요.
